# `drop/fonts/`

Brand font files — `.woff2`, `.woff`, `.otf`, `.ttf` — **and the licence that
permits web use**.

The licence is not a formality and it is the part people miss. A desktop licence
lets you set the font in Word and in your printed leaflets; it does **not** let you
serve the file from a website. They are separately priced, and shipping a font you
only hold a desktop licence for is a real liability, not a technicality.

Drop the licence PDF or the receipt in alongside the files. If you cannot find it,
say so — the build picks the closest freely-licensed match and tells you it did.
