# `drop/logo/`

The actual logo files. The vector one (`.svg`, `.ai`, `.eps`, `.pdf`) if it exists —
that is the one that stays sharp at every size and on a retina screen.

A screenshot of your logo off your old site is worth dropping too. It is better
than nothing and it tells the build what the mark actually is.

**Nobody here will redraw it.** A redrawn logo is a lie about your identity, and
the gate treats a generated one as exactly that. If the file is genuinely lost,
say so — the site is designed around not having it, rather than around a fake.
