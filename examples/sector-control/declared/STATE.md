# State - sector-control/declared

THIS FIXTURE EXISTS TO FAIL.

A managed build that declares `Sector: legal-services` and then ships the site a
general-purpose builder would produce for a law firm: no statement of regulated
status, no complaints procedure, no published costs for a reserved service, an
SRA number that traces to nothing, and no link to the register a client would
check it in.

Every one of those is a duty the firm's own regulator writes about the WEBSITE.
Every other family in this repo passes them.
